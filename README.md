# 毛泽东选集 · 经典篇章卡片网站

一个以**卡片形式**呈现毛泽东选集经典篇目的复古风格网站，采用当前最流行的前端技术栈构建。

> 资料整理仅供学习与研究之用。

---

## ✨ 特性

- **卡片式浏览** — 17 篇经典篇目以卡片网格呈现，每张卡片包含：写作年份、历史时期标签、一句话提要、经典名句、朱红印章。
- **复古中国风** — 做旧宣纸底色与纸纹、朱红双线书框、毛笔体「毛选」印章报头、思源宋体排版，营造民国书卷气息。
- **实时检索** — 顶部吸顶搜索框，支持按篇名 / 提要 / 名句模糊匹配。
- **时期筛选** — 按历史阶段快速过滤：大革命 / 土地革命 / 抗日战争 / 建设时期 / 全部。
- **详情弹层** — 点击卡片弹出「展卷阅读」面板，展示名句、提要与背景要点，带淡入上浮动画。
- **响应式** — 网格自适应，从手机到桌面均可良好浏览。

## 🛠 技术栈

| 类别 | 选型 |
| --- | --- |
| 框架 | **Vue 3**（Composition API + `<script setup>`） |
| 构建工具 | **Vite 5** |
| 语言 | JavaScript（ESM） |
| 样式 | 原生 CSS（CSS 变量 + Scoped Styles） |

## 📦 本地运行

```bash
# 安装依赖
npm install

# 启动开发服务器（默认 http://localhost:5173）
npm run dev

# 构建生产产物到 dist/
npm run build

# 本地预览构建产物
npm run preview
```

> **安装说明**：若 `npm install` 在受限环境中因 esbuild 原生脚本触发文件锁（EBUSY）失败，可改用
> `npm install --ignore-scripts`。esbuild 的 Windows 二进制会作为可选依赖（`@esbuild/win32-x64`）自动安装，运行时不受影响。

## 🔧 自定义

- **增删篇目**：编辑 `src/data/works.js`，按现有字段格式追加对象即可，网格与筛选会自动更新。
- **调整主题色**：修改 `src/styles/main.css` 中的 CSS 变量（`--paper` / `--red` / `--gold` 等）。
- **增时期分类**：在 `works.js` 的 `eras` 数组中添加条目，并使篇目的 `era` 字段与之对应。
